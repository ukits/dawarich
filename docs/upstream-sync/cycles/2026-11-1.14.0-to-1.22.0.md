## 정책: `superseded`

- **코드 이식 없음.** 대체한 **upstream 버전**을 카탈로그·이 파일에 기록한다.
- **작업 0이 아니다.** 사이클 종료 전 **검증(수동/스펙)** 으로 의도가 충족되는지 확인한다.
- 검증 실패 시 `adapted`로 되돌리거나 잔여 갭을 새 ID/재오픈으로 다룬다.
