### 사이클 전략

- upstream/master를 `sync/<ver>`로 분기한 뒤 카탈로그를 기능 단위로 이식
- cherry-pick 금지; 의도 재구현
- agent transcript JSONL은 저장소 이력이 아님 → 본 파일에만 누적

### F01
- 결정: defer
- 충돌: 없음 (선택 항목)
- 해결: 1.14.0의 Ruby/devcontainer/vendor를 그대로 씀. fork 로컬 환경 패치는 필요해지면 재검토

### F02
- 결정: adapted
- 충돌: 경로이동 · 대체됨 (Map v1/Leaflet 제거, `app/javascript/maps/` 삭제, points MVT 추가, 설정 패널 i18n)
- 해결:
  - Leaflet/`maps_controller`/`marker_factory` 패치는 drop
  - helper를 `maps_maplibre/utils/point_size.js`로 이동
  - GeoJSON points·anomalies와 tiled `points-mvt` 모두 반경 적용 (paint-hidden keepalive는 0 유지)
  - 설정 패널은 `t('.point_size')` 사용
- 완료 기준: 설정 슬라이더 2–12px, API `point_radius` persist+clamp, 지도 circle-radius 반영
